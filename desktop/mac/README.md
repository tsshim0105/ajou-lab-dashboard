# NISML Dashboard for Mac — 0.3.2

Mac용 첫 검증 버전입니다. Apple Silicon Mac, macOS 13 이상을 지원합니다.

## 사용

1. DMG를 열고 NISML Dashboard를 Applications(응용 프로그램) 폴더로 드래그합니다.
2. 앱을 실행하고 Mac 알림 요청에 ‘허용’을 선택합니다.
3. 대시보드에서 기존 GPT 계정으로 로그인합니다. 사이트의 기존 접근 권한을 사용합니다.
4. 하단 ‘연결됨’을 확인합니다. 창 상단 알림 메뉴의 ‘Mac 알림 허용 · 테스트’에서 테스트 알림을 표시합니다.
5. 빨간 닫기 버튼은 창만 숨깁니다. 메뉴 막대의 연구실 로고로 다시 열 수 있습니다.
6. 완전히 종료하려면 메뉴의 ‘앱 완전종료’ 또는 Command-Q를 사용합니다.
7. 자동 실행은 앱 창 상단의 설정 메뉴에서 직접 선택합니다. 설치 직후에는 켜지지 않습니다.

## 알림 방식과 한계

웹 푸시/VAPID 설정은 사용하지 않습니다. 앱의 로그인 세션으로 약 60초마다 기존 보호된 대시보드 API를 조회하고 macOS 로컬 알림을 표시합니다. 현재 API의 응답 중 계정 식별과 알림만 해석하며, 연구비·인건비 등 나머지 응답 내용은 파일로 저장하지 않습니다. 최초 접속에서는 기존 알림을 기준으로 삼아 과거 알림을 한꺼번에 띄우지 않습니다. 이후 새 알림을 계정별로 중복 제거합니다.

창이 숨겨져 있어도 앱이 실행 중이면 조회합니다. Mac 잠자기·오프라인·앱 완전 종료 상태에서는 즉시 알리지 못합니다. 깨어나면 재조회하며 서버에 보관된 최근 알림 범위 안에서 확인합니다. 로그인 만료 또는 권한 변경은 서버가 적용하며 재로그인이 필요할 수 있습니다. 집중 모드와 시스템 알림 설정에 따라 배너가 보이지 않을 수 있습니다.

앱은 자체 WebKit 저장소에 로그인 세션을 유지합니다. 다른 브라우저의 쿠키·비밀번호를 읽지 않으며 비밀번호를 별도로 수집하거나 저장하지 않습니다. 새 소식 확인에는 이 앱의 해당 사이트 쿠키만 사용합니다. 외부 서버 리디렉션에는 쿠키를 전달하지 않습니다. 앱 로그아웃은 앱 내 웹 저장소와 표시된 알림을 지웁니다.

## 검증 상태

- ARM64 실행 파일 빌드 및 ad-hoc 코드 서명 검증 성공.
- 중복 알림, 계정 분리, 첫 로그인 기준 처리, 안전한 URL 및 쿠키 범위 13개 검증 통과.
- 이 Mac에서 앱 내부의 교수 계정 대시보드 표시 및 서버 조회 연결 확인.
- 실제 신규 연구 기록을 만드는 운영 데이터 변경 테스트는 수행하지 않음.
- 창을 닫은 상태의 실제 새 알림 배너, 장기 세션 만료, 재부팅 자동 실행은 추가 현장 검증 필요.

현재 빌드는 이 Mac에서 테스트하는 개발 버전이며 Developer ID 서명과 Apple 공증은 아직 없습니다. 다른 학생들의 Mac으로 배포하기 전에는 정식 서명·공증이 필요합니다. macOS 보안 경고를 우회하거나 보안 설정을 끄지 마세요.

## 개발

빌드: `./build.sh` (Apple Command Line Tools, Python 3 필요)

테스트:

```
xcrun swiftc -swift-version 5 -module-cache-path build/ModuleCache Sources/Core.swift Tests/main.swift -o build/core-tests
build/core-tests
```

라이브 사이트 소스나 데이터는 이 앱 제작 과정에서 수정하지 않았습니다.

## 0.3.2 메뉴 구성

메뉴 막대의 연구실 아이콘: 홈페이지 열기 / 대시보드 열기 / 로그아웃 / 앱 완전종료.

앱 창 상단: 홈페이지 / 새로고침 / 알림 / 설정 아이콘. 중앙 NISML 타이틀과 테두리 없는 SF Symbols 아이콘을 사용하는 콰이어트 미니멀 디자인입니다. 대시보드 버튼은 삭제했습니다. 알림 조회·허용·테스트·시스템 알림 설정, 자동 실행과 브라우저 열기는 이곳 및 macOS 앱 메뉴에서 제공합니다. 연결 상태는 창 하단에 표시합니다. 0.1.0에서 사용자에 의해 실제 Mac 알림 배너 표시가 확인되었습니다.

## 알림 클릭 동작
앱 창이 이미 열려 있으면 클릭한 알림만 제거하고 현재 화면과 편집 상태를 유지합니다. 창이 닫혔거나 최소화 또는 앱 숨김 상태이면 기존 창을 다시 열고 해당 알림 항목으로 이동합니다.

## 0.3.3 최근 알림
트레이의 ‘최근 알림 보기’에서 로그인 계정의 최신 알림 5개를 확인합니다. 서버 알림과 계정별 로컬 기록을 합쳐 날짜순으로 정렬하며, 알림 센터에서 숨긴 항목도 남습니다. 로그아웃·권한 만료 시 목록을 숨깁니다. 그룹미팅 알림 클릭 시 일정 탭을 엽니다.

## 0.4.0 연구미팅 플로팅 패널

교수 계정에서 회의 녹음을 시작하면 밝은 민트·하늘색·라벤더 패널이 표시됩니다. 현재 미팅을 누르면 3열 목록과 미분류가 펼쳐집니다. 미팅 선택은 녹음을 끊지 않고 시간표시를 추가합니다. 일시정지·재개·저장 후 종료를 패널에서 조작할 수 있습니다. 커서가 벗어나면 0.45초 뒤 투명도 78%, 돌아오면 100%가 됩니다.

녹음은 Mac의 마이크 권한을 요청한 후 시작합니다. 창의 빨간 닫기 버튼은 화면만 숨기므로 녹음과 패널이 유지됩니다. 앱 완전 종료·로그아웃·페이지 새로고침은 녹음과 저장이 끝난 뒤 가능합니다. 학생 화면에는 표시하지 않습니다. 일반 웹 브라우저는 기존 녹음 기능을 유지합니다.

AAC 24kHz 모노 녹음 원본을 사용자 Application Support/NISML Dashboard/Meeting Audio에 먼저 저장합니다. 최대 1시간 후 자동 종료하며, 서버 업로드와 회의 저장 완료 후 로컬 원본을 지웁니다. 업로드 실패 시 파일은 남고 동일 조각 번호로 재전송하여 중복을 막습니다. 앱이 다시 열렸을 때 회의 녹음 시작을 누르면 중단된 회의를 먼저 복구합니다. 마이크 장치 오류·강제 종료·수동 잠자기에서는 연속 녹음을 보장할 수 없으며, 강제 종료된 m4a는 복구되지 않을 수 있습니다.

이 빌드는 Apple Silicon/macOS 13 이상용 개발 서명 버전으로, 기존처럼 Apple 공증은 없습니다. Windows 앱 지원은 포함하지 않습니다. 새 네이티브 기능은 0.4.0 앱 설치가 필요합니다.

검증: Mac 빌드/서명, URL·계정·알림 범위 검사, 웹 녹음·권한·주제 전환·일시정지·업로드 재시도 검사 통과. Mac 잠금으로 실제 패널 클릭 및 호버 검증은 미완료이며, 실제 마이크 녹음은 자동으로 시작하지 않았습니다.

## 0.4.1 패널 조작
패널은 커서 위치에 관계없이 항상 불투명도 78%를 유지합니다. 왼쪽 점 모양 손잡이를 누른 채 드래그하면 이동합니다. 주제 선택·일시정지·종료 버튼은 드래그와 분리되어 있습니다. 대시보드의 ‘이번 전사 폐기’는 현재 회의의 전사와 미확정 요약만 제거하며 녹음 원본·다른 회의·비용 사용 내역은 보존합니다. 확정 요약이 있거나 AI가 처리 중이면 폐기를 막습니다.

## 0.4.2 참여 학생 기반 빠른 전환
현재 연구주제의 열람 학생이 한 명 이상 겹치는 주제를 플로팅 바 위쪽 3열 빠른 전환에 표시합니다. 마지막 칸은 미분류이며, 다른 연구주제는 펼쳐서 선택합니다. 주제를 바꾸면 새 주제의 학생 기준으로 다시 묶고, 미분류에서는 직전 기준을 유지합니다. 녹음·일시정지·종료, 78% 불투명도, 드래그 손잡이는 유지됩니다. 앱 업데이트가 필요합니다.

## 0.4.3 트레이 업데이트 확인
트레이와 설정 메뉴의 ‘업데이트 확인’을 누르면 설치된 버전과 서버의 최신 Mac 버전을 숫자로 비교합니다. 새 버전만 자동 다운로드하며, 파일 크기와 SHA-256 확인 후 다운로드 폴더에 저장하고 Finder에서 표시합니다. 중복 실행·다운그레이드·외부 주소·손상 파일을 막고 기존 파일을 덮어쓰지 않습니다. 업데이트 확인은 버튼을 누를 때만 실행합니다. 앱을 자동 종료하거나 설치하지 않으므로 회의 녹음은 계속됩니다. 녹음 완료 후 앱을 종료하고 교체합니다. 홈페이지의 설치 파일 링크는 기본 브라우저로 넘겨 WebKit에서 다운로드가 멈추던 문제를 해결합니다. 이 기능을 처음 쓰려면 0.4.3을 브라우저에서 한 번 설치해야 합니다.
