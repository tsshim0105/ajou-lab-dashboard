# Ajou Lab Dashboard

연구실의 논문·학회 발표·연구비·인건비 기록을 한곳에서 확인하는 대시보드입니다. 기존 현장실습 대시보드의 파란색 탭과 표 중심 구성을 활용했습니다.

## 기능
- 연구실 현황과 연도별 기록
- 논문·학회 발표 검색, 발표 유형 필터
- 연구비 월별 기록과 인건비 지급 계획
- 기존 양식의 엑셀 업로드 및 표 CSV 저장
- 교수님·학생 조회 범위 구분
- 모바일 레이아웃과 다크 모드

논문은 게재 상태를 추정하지 않고 등록 기록으로 표시합니다. 인건비 계획과 실제 지급을 구분하며 원본의 불일치를 알립니다. 구글 시트 자동 동기화는 미연결입니다.

## 로컬 실행
Node.js 22 이상에서 `npm start` 후 http://127.0.0.1:4173 에 접속합니다. 로컬 실행은 개인 검토용입니다. 최초 실행 시 자료·계정 관리에서 기존 엑셀을 업로드합니다. `npm test`로 테스트하고 `npm run build`로 빌드합니다.

이 공개 저장소에는 프로그램 코드만 포함합니다. 원본 엑셀, 실제 연구실 자료, 개인 검토용 HTML 및 운영 설정은 포함하지 않습니다. 온라인 실행 환경은 별도로 구성합니다. 로컬 실행을 외부 공유용 서버로 사용하지 마세요.

엑셀의 저장된 수식 계산값을 사용하므로 업로드 전 재계산 후 저장하세요. 최신 브라우저가 필요합니다. 지원 양식은 data.js에 정의되어 있습니다.
